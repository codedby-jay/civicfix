# CivicFix

**Report. Track. Fix.**

AI-powered civic issue management platform for reporting, classifying, prioritizing, clustering, and tracking real-world infrastructure problems.

## Phase 1

This repository currently includes the frontend foundation only: design system, reusable components, landing page, authentication UI, and application route shells.

There is no backend, database, or live authentication in this phase.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

The app serves at `http://localhost:5173`.

```bash
npm run build
npm run lint
```
